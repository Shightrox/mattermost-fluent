# Source provenance

This public repository starts from a source snapshot of the Mattermost Fluent client-side fork, based on [Mattermost Desktop](https://github.com/mattermost/desktop), 6.3 code line.

The development checkout's earliest available upstream commit is 274602892a4391ac8c455cc09bdb52632ab282a9. The published snapshot was prepared from local Fluent commit e9da6c9, with publication-specific documentation and workflow changes.

The original copyright headers, license and attribution notices remain intact. Local development commit metadata is not included. Runtime profiles, sessions, logs, build artifacts and working-server data are excluded. Showcase images use synthetic data; see SHOWCASE.md.

Upstream organization-specific release, signing and scheduled workflows are replaced by a Windows source check/build workflow. This repository does not publish upstream binaries or claim an official Mattermost release.
