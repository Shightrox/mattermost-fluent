# Fluent v7 — реализация и ревью

2026-09-07. Этап: развитие alpha, не завершённый релиз 1.0.

## Что изменилось

Общая композиция описана в `FLUENT-DESIGN.md`. Переписка теперь имеет одно читаемое
полотно; навигация рисует материал один раз, без повторного затемнения вложенного
списка. Заголовок и редактор принадлежат переписке, тред — отдельной поверхности.
Сохранены штатные React-узлы, действия и геометрия виртуализированных строк.

Добавлены общие токены, собственные SVG-контуры для известных иконок, согласованные
стили настроек и стартовых экранов, собственная иллюстрация. Набор иконок генерируется
из `scripts/generate-fluent-icons.cjs` и используется оболочкой и webapp.

Настройки локального акцента: Небо, Ирис, Шалфей; размер сообщений: обычный/крупный.
У светлого и тёмного оформления разные оттенки акцента. Старые профили получают
defaults; неподдерживаемые значения отклоняет валидатор. Серверные настройки темы
не изменяются.

## Найдено и исправлено при проверке

- Минимальная высота 46 px не вмещала новую строку 22 px и отступы 25 px.
  Исправлены пустые поля основного редактора и ответа в треде.
- Настоящий AutosizeTextarea использует отдельный элемент `*-reference` с тем же
  классом. Он оставался на старой типографике и давал 65 px вместо нужных 69 px
  для двух строк. Типографика видимого поля и измерителя синхронизирована.
- При смене размера шрифта webapp не всегда сразу пересчитывает inline-высоту.
  Ограниченный ResizeObserver наблюдает известные измерители и корректирует только
  собственный CSS minimum, учитывая max-height. Значение, выделение и отправку
  по-прежнему контролирует webapp. При отключении удаляются observer и CSS-свойства.
- Нативные иконки часто имеют класс `icon-name` без дополнительного `icon`.
  Генератор теперь учитывает обе формы.
- Цвет непрозрачного fallback окна зависел от системной темы вместо явно выбранной.
  Теперь используется разрешённая локальная тема клиента.
- Команда панели переведена на `ipcValidate` со схемой разрешённых значений;
  проверка trusted sender и отправка только активной вкладке сохранены.

## Проверки

- `npm run check`: lint, TypeScript, конфигурация сборки и unit suites.
- `npm run test:fluent`: реальный sandboxed Electron, production preload, тема,
  иконки/счётчики, редактор, переключения, scope и cleanup.
- `scripts/test-fluent-lab.cjs`: настоящий Mattermost Server 11.10.0 в локальном
  Docker, синтетические аккаунт, сообщения и файл. Подключён production preload.
- Проверены отправка из редактора, загрузка/отправка текстового вложения,
  сохранение многострочного черновика после reload и изменения оформления.
- Проверены обе темы, три акцента, размер 15/17 px, открытие треда, пустое поле
  ответа, немедленный перерасчёт многострочного поля при смене размера текста.
- Проверены окна 1440×960, 1200×900, 840×680 и web zoom 1/1.25/1.5. Это матрица
  размеров и web zoom на текущем Windows DPI, а не тест всех физических мониторов.
- Рабочий сервер: только чтение геометрии, поиск, Escape/фокус и проверка счётчиков.
  Рабочие сообщения и файлы не отправлялись.

Кадры `artifacts/fluent-lab-*.png` содержат только синтетические данные настоящего
локального сервера. Стенд запускается через compose-файл в `scripts/fixtures`,
затем `node scripts/seed-fluent-lab.cjs` и `node scripts/test-fluent-lab.cjs`.
Доступ лаборатории опубликован только на loopback. Данные авторизации лаборатории
находятся в игнорируемой папке artifacts и не включаются в пакет.

## Что ещё не завершено

Релизный TODO остаётся действующим. Не завершены полный визуальный инвентарь,
все варианты SSO/MFA/Calls/плагинов, серверы 11.7–11.9, ARM64, физическая DPI-матрица,
доказанный прирост производительности в активном окне, длительный RC-прогон,
публичный подписанный установщик и собственный канал обновлений.

Полностью переписанный WinUI-клиент не создавался. Эта реализация использует
Electron и адаптирует серверный webapp; неизвестные разметки требуют отдельной
проверки. Нельзя выдавать сохранение upstream-функций или пройденные тесты одного
сервера за завершённую совместимость всей матрицы.
