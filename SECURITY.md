# Security

This unofficial fork is a preview and does not have a guaranteed security response time. Keep your server and client dependencies updated.

For vulnerabilities introduced by this fork, use this repository's **Security → Report a vulnerability** private reporting flow. Do not post secrets or exploit details in public issues.

For vulnerabilities in unmodified Mattermost components, follow [Mattermost's disclosure process](https://mattermost.com/security-vulnerability-report/). Mattermost does not maintain or support this fork.
